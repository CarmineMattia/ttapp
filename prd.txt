# Overview
TimeYeet is a modern, user-friendly time-tracking application designed for professionals (target age 25-50) who need to manage work hours across different projects, departments, or tasks. It aims to simplify time tracking with an engaging interface and provides essential export features, specifically a custom "Ferrarini-style" CSV format. The primary goal is to make hour logging intuitive and visually appealing, reducing the administrative burden for users juggling multiple responsibilities.

# Core Features

## Core Clocking & Session Management
-   **Clock In/Out Controls:** Traditional button-based interface using shadcn/ui components for clocking in/out and managing work sessions.
-   **Status System:** Visual indicators (Green: Working, Yellow: Paused, Grey: Logged Off) provide immediate feedback on the user's current state, reflected in the UI's color scheme.
-   **Manual Pause/Resume:** Dedicated pause/resume buttons for managing break time, tracked separately from work time.
-   **Overtime Tracking:** Automatically activates after 8 hours of work if not clocked out, visually indicated by a purple highlight and tracked in a separate "Extra Hours" counter.
-   **Auto-Logout:** Logs the user out automatically after 12 continuous hours (configurable legal limit) with a notification.
-   **Export Functionality:**
    -   Standard CSV/Excel export of shift data
    -   Custom "Ferrarini-style" CSV export with specific header format
    -   PDF export option

# Technical Architecture

## Technology Stack
-   **Frontend Framework:** Next.js 14 (App Router)
-   **Language:** TypeScript 5.x
-   **UI Components:** 
    -   shadcn/ui components
    -   Radix UI primitives
    -   Lucide icons
    -   TailwindCSS for styling
-   **State Management:** Zustand
-   **Backend:** Next.js API Routes
-   **Database:** Supabase (PostgreSQL)
-   **Authentication:** Supabase Auth
-   **Charts:** Recharts
-   **Forms:** React Hook Form + Zod validation
-   **Date/Time:** date-fns
-   **Animations:** Framer Motion
-   **Testing:** Jest + React Testing Library
-   **Development Tools:**
    -   ESLint
    -   Prettier
    -   Husky for git hooks
    -   TypeScript strict mode
    -   PostCSS
    -   Autoprefixer

## Data Models
-   **Users:** Standard user info (id, email, name, profile settings, avatar config, credits). Managed by Supabase Auth, extended with a `profiles` table.
-   **Shifts:** (Key table)
    -   `id`: Primary Key
    -   `user_id`: Foreign Key to Users
    -   `start_time`: Timestamp
    -   `end_time`: Timestamp (nullable while shift is active)
    -   `total_duration_ms`: Calculated duration
    -   `break_duration_ms`: Accumulated duration from pause periods
    -   `overtime_duration_ms`: Calculated duration beyond 8 hours
    -   `department`: VARCHAR (Optional, user input)
    -   `project`: VARCHAR (Optional, user input)
    -   `notes`: TEXT (Optional, user input)
    -   `mood`: VARCHAR (Optional, logged from modal)
    -   `reflection`: TEXT (Optional, logged from modal)
    -   `created_at`, `updated_at`: Timestamps
-   **Aphorisms:** Table to store Italian aphorisms
-   **Avatars:** Configuration and customization options for generated avatars

## APIs and Integrations
-   **Internal APIs:** Next.js API routes with authentication middleware
-   **Supabase Integration:** Direct client library usage with RLS policies
-   **Avatar Generation API:** Integration for automatic avatar generation

## Infrastructure Requirements
-   **Hosting:** Vercel for Next.js deployment
-   **Database:** Supabase Cloud
-   **Asset Storage:** Supabase Storage for avatars and exports
-   **Monitoring:** Vercel Analytics
